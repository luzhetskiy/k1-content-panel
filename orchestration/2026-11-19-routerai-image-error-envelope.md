# Фикс: error-конверт RouterAI внутри HTTP 200 (генерация картинок)

Дата: 2026-11-19. Ветка: `fix/routerai-image-error-envelope`.

## Контекст (Directions)

Расследование партии №171 (tedwood-uzel.ru, 15/15 статей failed,job 1990):
RouterAI images отдаёт **HTTP 200** с телом
`{"error": {"message": "Провайдер вернул пустой ответ (HTTP 404). Попробуйте ещё раз.",
"code": 503, "metadata": {"provider_error_code": "404"}}}` — upstream модели
`openai/gpt-5.4-image-2` умер между 17 и 18 ноября 2026 (404 при любых параметрах,
воспроизведено из прод-воркера; дифференциальные тесты без output_format/1024x1024/

лезет в `body["data"]` → `KeyError: 'data'`, сообщение провайдера теряется,
повтор не делается. Та же ошибка в партиях 168/169/170. Текстовый эндпоинт
(OpenAI SDK) отдаёт честные HTTP-статусы — тексты генерировались штатно.

Прод разблокирован отдельно 2026-11-19: `image_model` переключён на
`openai/gpt-image-2` через SettingsService (проверено: генератор собирается
с новой моделью; контрольная генерация с прод-параметрами вернула `data`).

## Цель

`ImageGenerator.generate()` распознаёт error-конверт RouterAI в теле 200-го ответа:
1. Админ видит сообщение провайдера и code вместо `KeyError: 'data'`.
2. Transient-коды конверта (429/500/502/503/504) ретраятся в существующем
   бюджете попыток (max_retries, backoff) — как HTTP-сбои.
3. Нетранзиентные коды конверта (400/401/404/…) — немедленный ImageError
   без повтора (тот же принцип, что `_NON_RETRYABLE` в app/ai/text.py).
4. Действительно нечитаемое тело (не JSON, нет `data`, битый b64/картинка) —
   по-прежнему без повтора, но с фрагментом тела ≤200 символов в сообщении.

## Не-цели

- Не менять таймауты и бюджет попыток (TIMEOUT=180, IMAGE_MAX_RETRIES=2).
- Не трогать текстовый клиент, водяной знак, кроп, логику настроек/моделей.
- Не менять поведение при честных не-200 статусах (уже ретраятся).

## Дизайн (app/ai/images.py)

Ветка `response.ok`:
1. `response.json()` отдельно: `ValueError` → ImageError «тело не JSON: <фрагмент>», без повтора.
2. Конверт: тело — dict с непустым `error` (dict со `message`/`code` либо строка).
   `code` приводится к int, не приводится → None. Константа
   `TRANSIENT_ERROR_CODES = {429, 500, 502, 503, 504}`.
   - transient → `last_error = "ошибка в теле 200 (code N): <message>"`, следующая попытка;
   - иначе → немедленный ImageError «RouterAI images отклонил запрос — <last_error>».
3. Нет конверта → `data[0].b64_json` → to_webp как раньше; сбой разбора →
   ImageError «…разобрать (тип): exc; тело: <фрагмент>», без повтора.
