# Стандарт объёма и наполнения текстов страниц строителей

Регламент для текстовых полей `company_info`, которые агент пишет на шаге 2
(`about_company`, `specialization`, `projects_services`, `benefits`).
Причина появления: без ориентира тексты выходили слишком короткими — часть
`about_company` была < 200 символов, вспомогательные блоки ~125–143 символа
(одно-два предложения). См. skills `scrape-company-info`, `rephrase-company-info`.

## Целевой объём

| Поле | Цель, символов | Ориентир |
|------|----------------|----------|
| `about_company` | **350–600** | 2–3 абзаца |
| `specialization` | **150–300** | 1–2 абзаца |
| `projects_services` | **150–300** | 1–2 абзаца или перечень |
| `benefits` | **150–300** | 1–2 абзаца или перечень |

Это ориентир, а не жёсткий валидатор: небольшой выход за границы допустим,
качество и достоверность важнее попадания в диапазон.

## Факты и объём

- **Конкретные факты не выдумывать.** Цифры (годы работы, число объектов,
  площади, цены), названия реализованных проектов, имена, награды, гарантийные
  сроки — только если они прямо есть на сайте-источнике.
- **Общие нейтральные формулировки — разрешены** для добора объёма: описание
  типового процесса строительства, применяемых материалов и подходов, этапов
  работы, зон ответственности — то, что справедливо для любой добросовестной
  компании отрасли и не является проверяемым утверждением о конкретной фирме.
- Прежнее правило «нет данных → пустая строка» **смягчается**: если по компании
  мало данных, блок не оставляем пустым, а наполняем общими отраслевыми
  формулировками до нижней границы объёма. Пустой блок допустим, только если
  поле неприменимо к компании по смыслу.
- Язык нейтральный, **без суперлативов** («лучший», «№1», «ведущий») и без
  маркетинговых обещаний.

## Проверка

```bash
sqlite3 execution/data/companies.db "
SELECT company_id,
       length(coalesce(about_company,''))     AS about,
       length(coalesce(specialization,''))    AS spec,
       length(coalesce(projects_services,'')) AS proj,
       length(coalesce(benefits,''))          AS benef
FROM company_info
WHERE length(coalesce(about_company,'')) < 350
ORDER BY about;"
```
