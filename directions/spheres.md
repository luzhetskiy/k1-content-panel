# Сферы деятельности строительных компаний

Используется в параметре `--sphere` скриптов.

## Жилищное строительство

| Сфера | Параметр --sphere |
|-------|------------------|
| Многоквартирные застройщики | `застройщики` |
| Строительство частных домов | `строительство частных домов` |
| Коттеджные посёлки | `коттеджные посёлки` |
| Таунхаусы | `строительство таунхаусов` |

## Деревянное домостроение

| Сфера | Параметр --sphere |
|-------|------------------|
| Деревянное домостроение | `деревянное домостроение` |
| Дома из бруса | `дома из бруса` |
| Дома из бревна | `дома из бревна` |
| Каркасные дома | `каркасные дома` |
| Клееный брус | `дома из клееного бруса` |

## Малые архитектурные формы

| Сфера | Параметр --sphere |
|-------|------------------|

| Беседки | `беседки на заказ` |
| Гаражи | `строительство гаражей` |
| Хозяйственные постройки | `хозяйственные постройки` |
