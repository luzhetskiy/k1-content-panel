# Проект: Сбор данных по строительным компаниям

## Цель

Автоматизированный pipeline для сбора, обогащения и публикации информации о строительных компаниях России.

> **Весь процесс выполняется локально на этой машине, без внешних LLM-API.**
> Ключи ANTHROPIC/TAVILY не нужны. Описательный текст для страниц (шаг 2) готовит
> оркестратор (агент): сам заходит на сайты компаний и пишет описание — никаких
> вызовов Claude API. Единственные внешние обращения — загрузка сайтов компаний
> (публично) и публикация на целевые сайты по их API-токенам (`SITE_API_TOKEN_*`).

## Источник данных

Основной источник компаний — готовая выгрузка **Яндекс.Карт** в xlsx
(`builders_yandex_2026-07-10.xlsx`, лист «Яндекс»). Из неё берутся не только
список компаний, но и **достоверные** контакты, координаты, отзывы/рейтинг,
логотип и соцсети. Это заменило прежний медленный поиск по интернету (шаг 1).

> Текущая выгрузка покрывает две тематики: «Строительство дачных домов и
> коттеджей» и «Архитектурные бюро». Для других сфер нужна новая выгрузка.

## Шаги pipeline

| Шаг | Скрипт | Что делает |
|-----|--------|------------|
| 1 | `step1_import_yandex.py` | Импорт компаний из выгрузки Яндекс.Карт с фильтром по региону/сфере; достоверные контакты, координаты, отзывы, логотип — сразу из файла |
| 2 | `step2_scrape_company.py` | Локально скачивает текст сайтов в файлы; описание (about/специализация/услуги/преимущества) пишет агент, читая их, и применяет через `--apply-text`. Контакты/координаты не трогает |
| 3 | `step3_fill_template.py` | Генерация HTML-страницы по шаблону builders.html |
| 4 | `step4_verify_local.py` | Верификация фактов субагентом |
| 5 | `step5_publish_batch.py` | Создание страницы (черновик) через API целевого сайта |

> `step1_search_companies.py` (поиск по интернету через DuckDuckGo) — устаревший,
> оставлен как запасной вариант для сфер/регионов, которых нет в выгрузке.

## Входные параметры

- **Регион** — город («Самара»), область («Самарская область») или «Россия» (весь файл).
  Компания подходит, если `--region` совпадает с колонкой **Город** ИЛИ входит в **Регион**.
- **Сфера деятельности** — фильтр по колонке **Категории** (маппинг в `step1_import_yandex.py`).

## Данные о компаниях (хранятся в SQLite)

Из выгрузки Яндекс.Карт (шаг 1, достоверно):
- Регион, сфера, название, сайт
- Контакты: телефон, email, адрес, график работы
- Координаты (широта/долгота)
- Количество отзывов (`reviews_count`), рейтинг (`rating`)
- Логотип, ссылка на карточку организации (`yandex_url`)

Из скрейпинга сайта (шаг 2):
- Описание компании, специализация, услуги, преимущества

## Правила сбора данных

- Собирать только компании с собственным сайтом (колонка **Сайт** не пуста)
- Ранжировать по числу отзывов из Яндекс.Карт (`reviews_count`)
- Контакты и координаты брать из выгрузки — они достоверны, не скрейпить и не геокодить
- Не выдумывать факты: описание — только то, что явно указано на сайте компании
- Использовать нейтральный язык без суперлативов

## Зависимости

Установить из `execution/requirements.txt`:


Создать файл `.env` по образцу `.env.example`.
